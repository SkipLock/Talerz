# Talerz

Licznik kalorii na telefon: posiłki z makro, zestawy, kroki, treningi, waga i historia z prognozą.
Aplikacja działa w przeglądarce i instaluje się jak aplikacja (PWA). Dane zostają w telefonie użytkownika.

Instalacja: otwórz stronę aplikacji w Chrome na Androidzie i wybierz „Zainstaluj aplikację”.
