# Macroo

Licznik kalorii i makro na telefon: posiłki, zestawy, kroki, treningi, waga i historia z prognozą.
Cel do wyboru: schudnąć, utrzymać albo przytyć.

- **Android (z Samsung Health / Health Connect):** pobierz [macroo.apk](https://github.com/SkipLock/Talerz/releases/latest/download/macroo.apk).
- **Przeglądarka:** [skiplock.github.io/Talerz](https://skiplock.github.io/Talerz/), potem „Zainstaluj aplikację”.

Dane zostają w telefonie użytkownika.
